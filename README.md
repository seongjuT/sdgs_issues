# SDG 이슈랩 (학생용 웹사이트)

SDGs 목표별 사회 이슈를 탐색하고, 이슈에서 아이디어와 서비스 컨셉을 도출하는 수업용 사이트입니다.
로그인 없이 PC와 휴대폰 브라우저에서 동작합니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 사이트 첫 화면 (이슈 탐색 / 아이디어 랩 / 서비스 설계) |
| `assets/style.css` | 화면 스타일 |
| `assets/app.js` | 동작 스크립트 |
| `data/issues.js` | 이슈 데이터. 새 이슈를 반영할 때 이 파일만 바꾸면 됩니다 |

## 바로 열어 보기

압축을 풀고 `index.html`을 더블클릭하면 인터넷 연결 없이도 브라우저에서 열립니다.
(글꼴만 인터넷에서 받아오며, 오프라인이면 윈도우 기본 글꼴로 표시됩니다.)

## 학생에게 공개하기 (배포)

### 방법 1. GitHub Pages (무료, 추천)

1. GitHub에 로그인하고 새 저장소(Repository)를 만듭니다. 예: `sdg-issue-lab`, 공개(Public).
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일과 폴더(`index.html`, `assets`, `data`)를 그대로 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 정하고 저장합니다.
4. 1~2분 뒤 `https://<GitHub아이디>.github.io/sdg-issue-lab/` 주소가 생깁니다. 이 주소를 QR 코드로 만들어 학생에게 안내하세요.

웹프로그래밍 수업에서 학생들이 직접 저장소를 만들어 배포해 보는 실습으로도 쓸 수 있습니다.

### 방법 2. Netlify

1. Netlify에 로그인한 뒤 **Add new site → Deploy manually** 화면을 엽니다.
2. 이 폴더를 통째로 끌어다 놓으면 주소가 바로 만들어집니다.
3. 이슈를 갱신할 때는 같은 사이트의 **Deploys** 화면에 폴더를 다시 끌어다 놓습니다.

## 새 이슈 반영하기

이슈 수집은 선생님용 페이지(claude.ai 아티팩트 "SDG 이슈랩")에서 계속 합니다.

1. 선생님용 페이지에서 **최근 이슈 수집하기**를 눌러 새 이슈를 모읍니다.
2. Claude에게 "SDG 이슈랩 사이트용 issues.js 만들어줘"라고 요청해 새 `issues.js` 파일을 받습니다.
3. 사이트의 `data/issues.js`를 받은 파일로 바꿔 다시 올립니다.
   - GitHub: 저장소의 `data` 폴더에서 **Add file → Upload files**로 같은 이름의 파일을 올리면 덮어써집니다.
   - Netlify: 폴더 전체를 다시 끌어다 놓습니다.

## 학생 아이디어 저장 방식

- 아이디어 랩에서 작성한 내용은 **학생이 쓰는 기기의 브라우저에만** 저장됩니다. 서버로 전송되는 개인정보는 없습니다.
- 같은 기기·같은 브라우저로 다시 열면 이어서 볼 수 있지만, 다른 기기에서는 보이지 않습니다. 브라우저 기록을 지우면 함께 지워집니다.
- 완성한 카드는 **파일로 저장**(마크다운 .md, 한글이 깨지지 않는 UTF-8 형식)이나 **복사하기**로 구글 클래스룸, 패들렛 등에 제출하게 하세요.
- 공용 PC에서 여러 학생이 쓰면 앞 학생의 카드가 남습니다. 제출 후 카드의 **삭제**를 누르도록 안내하세요.

## 교사용 페이지와의 차이

| 기능 | 교사용 페이지 (claude.ai) | 학생용 사이트 |
|---|---|---|
| 이슈 탐색·목표별 필터 | O | O |
| 최근 이슈 수집 버튼 | O | X (교사용에서 수집 후 파일 교체) |
| AI 아이디어 제안 | O | X (발상 카드로 대체) |
| 아이디어 보드 | 반 전체 공유 | 학생 기기에 저장 + 파일 제출 |
| 로그인 | claude.ai 계정 필요 | 필요 없음 |
